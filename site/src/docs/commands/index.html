Commands

Claude runs these for you. You can also drive the device yourself. Every command has --help, and --device <serial> picks a device when more than one is connected.

Runs

CommandWhat it does
doctorCheck the setup (adb, devices, Python, fast screen reads) and print the fix for each problem
start <name> --package <app>Start a test run: recording, evidence and report
stopFinish the run and write the report
statusShow the active run
cases import cases.csv --app <app>Bring test cases from a sheet (CSV, a pasted spreadsheet table, or Markdown) into a draft plan, keeping their IDs
plan review plans/x.planEvery requirement and case, its expected results and what proves each; everything still missing
plan approve plans/x.planRecord that you agreed to the plan's requirements, so a later change to them shows in the report
case plan TC-01 "title" --expect "…"Declare a case and its expected results first, so the report shows it even if it never runs
case start TC-01 "title" / case endGroup the steps between them into a test case
runs / reportList recent runs, or rewrite a run's report

Read the screen and act

CommandWhat it does
observeList what is on screen: index, id, text, label, position. --full prints long texts whole
tap "Pay now"Tap by text, id=, desc=, #index or 9%,6%
type "text" --into id=fieldType into a field. --env NAME types a secret from .env
key backPress back, home, enter, tab and other keys
scroll down --to "Text"Scroll until an element shows
launch / open-urlLaunch the app, or open a deep link
devices / packagesList connected devices, or installed apps

Check and record

CommandWhat it does
check "Payment successful"Verify it is on screen. Exact match; '~text' for partial. --for E1 says which expected result it proves.
check "Home" --setupA setup condition, as a plan's require writes it: if it does not hold, the case is blocked · precondition not met, never failed
wait "Home" --or "Error"Wait for a screen; stop early if the error shows instead
shot / noteSave a screenshot, or record an observation or bug

Navigate fast

CommandWhat it does
goto "wi-fi"Reach a screen by a route learned in earlier runs
mapShow what was learned: screens, names, routes
flow <name> / flowsRun a saved route, or list them

Plans and replay

CommandWhat it does
run plans/x.planRun every case of a plan file
replay <run>Run a recorded test again and re-check every result

Dashboard

CommandWhat it does
uiOpen the live dashboard
say "Logging in"Narrate the next step on the dashboard timeline
wait-message / wait-resumeListen for a dashboard message, or wait for Resume
