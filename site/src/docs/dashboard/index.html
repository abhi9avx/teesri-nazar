Live dashboard

A page on your own machine that shows a run as it happens and lets you steer the agent. Nothing is hosted or uploaded.

Start it

./tnazar ui                 # opens http://127.0.0.1:8765
./tnazar ui --port 9000     # if 8765 is busy

Start it in its own terminal, then ask Claude to test as usual. The page follows the active run by itself. Stop it with Ctrl-C.

What you see

PaneShows
TimelineEvery step with its time, checks as pass or fail, and each case's result and token cost. Slow steps over 5 s are highlighted.
ControlA message box, Pause and Resume, and a hidden field for an OTP or PIN.
ScreenThe phone screen, refreshed about every 1.5 s.

Steer the agent

  • Message. The agent hears it within about a second and changes course before its next step.
  • Pause. The next device step waits until you press Resume.
  • OTP or PIN. The dashboard types it into the focused field itself. The value never reaches the chat, a log or the disk.

Safety

  • Listens on 127.0.0.1 only and rejects other host names.
  • Every change needs a token created for that session.
  • Secrets live in memory only and are cleared when a new run starts.
