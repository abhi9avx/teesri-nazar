Tech stack

Small on purpose: an AI agent, a standard-library Python tool and adb. Your app needs no SDK and no changes.

Core

Claude CodeThe agent. Plans the cases, decides each step, judges the results.
Python 3.9+The tnazar CLI. Standard library only, no installs.
adbAndroid Debug Bridge: taps, typing, screenshots and logs.
UIAutomatorReads the screen's accessibility tree. Uses the UiAutomator2 server when present for ~0.05 s reads.

Optional connections

Figma MCPThe agent compares the build against the design frame and records the result as a check.
Atlassian MCPRead test cases and specs from Jira or Confluence.
Your databaseThe agent runs read-only queries against a test environment and records the query and result as a check. tnazar has no database code.

What stays local

PartWhere it runs
tnazar and device controlYour computer, talking to the device over adb
Live dashboard127.0.0.1 on your computer, not reachable from other machines
Reports, screenshots and logsThe runs/ folder on your computer
TelemetryNone. tnazar sends nothing anywhere
What the agent reads: screen text, screenshots, Figma frames, DB resultsSent to Anthropic's model as part of your Claude Code session, as with any Claude Code work

tnazar replay --visual also asks Claude Code to compare screenshot pairs. Check what a screen shows before you test it with real customer data.

Outputs

FileWhat it is
report.htmlThe report to share: every case, result and screenshot
report.mdThe same report in Markdown
events.jsonlEvery step as JSON, used by replay
ScreenshotsPNG evidence for every check, plus logs for crashes, ANRs and failed cases

How the tool is tested

  • Unit tests run against a fake device, so no phone is needed.
  • GitHub Actions runs them on Python 3.9 and 3.13 for every push.
  • A smoke script checks the live dashboard on a real device or emulator.

This website

Hand-written HTML and CSS, built by a standard-library Python script that turns CHANGELOG.md into the changelog pages. Hosted on GitHub Pages. No framework, no tracking.
